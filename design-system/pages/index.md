# Page Spec: index（首页）

> 覆盖 MASTER.md 的全局规则，定义首页特有规范。

## 布局结构

1. 顶部固定搜索栏（高度 96rpx，背景 #FFFFFF，阴影 --shadow-sm）
2. 分类快速入口网格（2行，每行4个，图标 80rpx + 文字）
3. 帖子列表瀑布/单列（单列，卡片间距 16rpx）
4. 右下角浮动发布按钮（直径 96rpx，--color-accent，图标 40rpx）

## 颜色覆盖

- 搜索栏背景：#FFFFFF
- 分类入口背景：var(--color-muted)
- 分类入口激活/悬停：rgba(124, 58, 237, 0.1)
- 发布按钮：var(--color-accent)

## 间距

- 搜索栏内边距：16rpx 24rpx
- 分类网格内边距：24rpx
- 分类项间距：16rpx
- 列表容器内边距：16rpx

## 交互

- 分类入口点击缩放 0.95，150ms
- 列表项点击触发 post-card 默认缩放
- 浮动按钮长按不动，点击有阴影扩散反馈

## 禁止

- 禁止在首页使用横向滚动的分类长条（该模式用于分类页）
- 禁止卡片出现阴影（遵循 Flat Design）
