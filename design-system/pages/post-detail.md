# Page Spec: post-detail（帖子详情）

## 布局结构

1. 图片轮播（高度 560rpx，指示点主题色）
2. 标题价格区（内边距 24rpx）
3. 发布者卡片（头像 80rpx，昵称 + 校区 + 认证）
4. 描述区（文字 28rpx，行高 1.6）
5. 标签/位置区
6. 底部固定操作栏（高度 112rpx，背景 #FFFFFF，上边框）

## 颜色覆盖

- 价格文字：var(--color-destructive)
- 收藏按钮激活：var(--color-destructive)
- 私信按钮：var(--color-accent)

## 间距

- 轮播与内容间距：0
- 内容区卡片间距：16rpx
- 底部操作栏内边距：16rpx 24rpx

## 交互

- 轮播图片点击全屏预览
- 收藏按钮切换状态并 toast
- 底部栏按钮高度 80rpx

## 权限

- 本人发布显示“编辑/删除”菜单
- 非本人显示“举报”入口
